# Project Notes

## Objective

Build a mini student information system that simulates core academic data management tasks similar to enterprise university systems.

## Business Problem

Universities need systems to manage student records, course data, enrollments, and reporting. This project simulates those workflows using a relational database and API layer.

## Key Technical Components

- PostgreSQL relational schema design
- SQL reporting queries using joins and aggregations
- Express API endpoints for CRUD operations
- Frontend integration with backend services

## Testing Performed

- Verified database table creation and foreign key relationships
- Tested GET, POST, PUT, and DELETE endpoints in Postman
- Tested frontend add/load/delete student functionality
- Validated report endpoint output

## Skills Demonstrated

- Database design
- SQL reporting
- API development
- Debugging
- Documentation
